# Higgs Boson ML project

How effectively can machine learning distinguish Higgs-boson signal events from background events, and how much does physics-informed feature engineering improve the classification?

This is based on the HIGGS dataset associated with Daniel Whiteson at the University of California, Irvine (Kaggle). The dataset contains simulated particle-collision events with low-level detector/kinematic features and high-level features derived using physics knowledge.
